# 裝備/資源圖示 SVG 重繪規格（v1）

> 目的：把現行 EO 點陣圖示（xBR 放大版，`public/icons/`）逐族替換為**原創 SVG**。
> 風格＝「真實系縮小」：以**遊戲原圖的構圖概念**為藍本（非描圖、非拓印 EO），
> 兵裝對應真實原型（46cm 三連裝、零式艦戦…）。著作權上為原創著作。
> 範例與驗收頁：claude.ai artifact「Fleet Chronometer — 圖示化預覽」。

## 通用規則

- viewBox `0 0 32 32`，顯示尺寸 16px（CSS 既有 `.g-icon`/`.m-icon` 不變）。
- 檔名沿用 icon id（`api_type[3]`）：`public/icons/equipment/<id>.svg`。
- 飛機＝上視圖；砲塔＝正面；色彩沿用遊戲的裝備色慣例。
- **機種徽章**（右下角）：
  - 單字＝**尖頂六邊形**（頂點朝上下）；雙字（夜戦/夜攻/重爆…）＝**圓矩形**。
  - **彩色外框＋同色文字、透明底**，維持小尺寸下的辨識度。
  - 參數化函式 `badgeHex(cx,cy,color,kanji)`／`badgeRect(cx,cy,color,kanji2)`
    已在預覽頁 JS 內，量產直接沿用。
  - 構圖注意：機體右下象限盡量留空，避免徽章與同色機翼/尾翼重疊降低辨識。
- 驗收：以 `qlmanage -t -s 128` 渲染後檢查透明背景、比例、徽章位置與 16px 可讀性，
  再於離線預覽頁確認整批圖示。

## 徽章顏色

徽章色規則＝「該機種的對應色」（外框與字同色）。各機種顏色以生成器與本表為準；
驗收時確認 16px 下的色彩對比與語意一致，避免把徽章色與狀態色混用。

## 交付與接線

1. 產出 `<id>.svg` 至 `public/icons/equipment/`，並由面板現有的 SVG 載入路徑使用。
2. 生成後確認描邊、尺寸正規化與亮暗主題可讀性；不得手改產生物。
3. 徽章 `<text>` 依賴系統 CJK 字型；若需跨平台像素一致，才評估將字形轉為 path。
