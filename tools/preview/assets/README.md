# 出擊預覽圖示素材

這些 PNG 僅供離線出擊分頁預覽使用，正式面板不會因預覽變更而改動。

- `yamato-north-style.png` 是砲艦／炮艦剪影的基準素材。之後預覽中需要艦炮艦影時，優先重用這個版本，不另畫新的船艦輪廓；支援未指定變體時也預設使用它。若要改用完整北卡或右半北卡，才使用同目錄的比較版本。
- `b25-lbas-support.png` 是陸航 B-25 俯視剪影。
- `comet-air-support.png` 是航空支援彗星艦爆俯視剪影。
- `bofors-40mm-aaci-mirrored.png` 是鏡像後的 Bofors 40 mm 對空 CI 剪影。
- `tracker-s2-asw-support.png` 是含雙螺旋槳的 Tracker S-2 俯視反潛機剪影，供對潛支援備案使用。
- `ka2-asw-support.png` 是 Ka-2 旋翼機側面剪影，供對潛支援現行方案使用。
- `friendly-anchor.png` 是去掉外框圓圈後只保留錨與海浪的友軍標示剪影，供連合艦隊友軍欄位使用。
- `deepsea-carrier-aircraft.png` 是使用者提供的深海艦載機圖轉成敵方 CDJ 紅色剪影，供敵方觸接圖示使用。
- `brass-crescent.png` 是依使用者提供的弦月輪廓轉成黃銅色、透明背景的月牙，供夜戰伴隨／主隊標示使用。
- BOSS 節點採用遊戲原始的赤鬼頭像（鬼角＋斜向發光眼）SVG 向量語彙，並在鬼臉中央完整保留各海域之英文字碼（如 `M`、`Z`），取代舊有的裝飾性 `W` 冠狀標記。

素材共同採用低彩度黃銅單色與透明背景，配合面板的低飽和度圖示語彙。
