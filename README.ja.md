# クロノメーター Fleet Chronometer

[English](README.md) | [繁體中文](README.zh-TW.md)

**艦隊これくしょん -艦これ-** 向けの受動型 COP（共通作戦状況図）ブラウザ拡張です。
艦隊・遠征・入渠・基地航空隊・海域進捗・戦闘予測・燃料弾薬の消費見積りを
1つのパネルにまとめ、検索・グラフ表示・バックアップが可能なローカル履歴を
保持します。

本プロジェクトはファンによる非公式ツールであり、**DMM.com および角川ゲームスとは
一切関係なく、公認・後援も受けていません**。「艦隊これくしょん -艦これ-」および
ゲーム内の全素材の著作権は、それぞれの権利者に帰属します。

## 主な機能

- **リアルタイムパネル** — 艦隊のHP／疲労／補給状態、遠征・入渠のカウントダウン
  （通知付き）、基地航空隊、海域ゲージの進捗。
- **戦闘予測** — 戦闘終了後のHP、rank、MVP、大破警告を、ゲームが送信する
  パケットから即座に算出します。
- **燃料弾薬の消費見積り** — 出撃中はマスの種類から推定し、帰投後は実数値で
  補正します。
- **出撃ログ** — 出撃ごとに1枚のカード：ルート、編成、マスごとの戦闘詳細、
  支援艦隊／基地航空隊の出撃波を記録し、KC3Kai battleplayer 形式のリプレイ
  として書き出せます。
- **資材ログ** — 8種類の資材を1枚の折れ線グラフにまとめ、イベント海域ごとの
  消費区間も集計します。
- **イベント作戦ボード** — 各海域の札（出撃制限タグ）付与ルールを追跡し、
  艦娘を誤ったルートに縛り付けてしまうのを防ぎます。
- **艦娘・装備一覧** — フィルタ・ソート可能な完全な保有一覧。
- **ローカルバックアップ** — 任意のフォルダ（例：Google Drive デスクトップの
  同期フォルダ）へのエクスポート／インポート。拡張機能なしでもリプレイを
  再生できるオフライン HTML ビューア付き。
- **ウィンドウ適応** — ゲーム画面をブラウザウィンドウに合わせる。大きさはウィンドウ枠で調整、ミュートも
  可能です。

## プライバシーと安全性（設計上の保証）

- **受動的な観測のみ** — ゲームが元々送信している通信を観測するだけで、
  リクエストの再送・改変・代理送信は一切行いません。
- **アカウント情報はブラウザの外に出ません** — `api_token` は保存・内部送信の
  前に必ず除去され、永続化されることはありません。
- **どこにもアップロードしません** — すべてのデータはブラウザローカルの
  IndexedDB に保存され、バックエンドサーバーは存在しません。
- **権限は最小限** — 特定の機能が必要とする場合にのみ要求します
  （例：ウィンドウ適応はボタンを押した時だけ DMM ゲームページへのアクセスを
  要求し、インストール時には一切要求しません）。

設計上の制約の全容はプロジェクト内部のドキュメントに記載しています。

## 技術スタック

[WXT](https://wxt.dev/) + TypeScript + [Dexie](https://dexie.org/)（IndexedDB）。
純粋なフロントエンド、Manifest V3、バックエンドなし。

## ソースからのビルド

```bash
npm install
npm run build        # .output/chrome-mv3 を出力 — 「パッケージ化されていない
                      # 拡張機能を読み込む」で読み込みます
npm run dev           # 開発モード（変更を自動リビルド）
npm test              # vitest テストスイート
```

`chrome://extensions` の「パッケージ化されていない拡張機能を読み込む」で
`.output/chrome-mv3` を指定してください。ソース変更後は再ビルドし、拡張機能の
再読み込みボタンを押してください。すでに開いているゲームタブは手動での
リロードも必要です（MV3 のコンテンツスクリプトの既知の制限です）。
